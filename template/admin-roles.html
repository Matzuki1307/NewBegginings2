Roles y permisos

Define qué puede hacer cada rol, qué tarjetas ve en su panel y cómo se comporta el formulario de ayuda.

    El rol administrador siempre tiene todos los permisos.

    Elige qué tarjetas aparecen en el panel de este rol. Una tarjeta visible solo se muestra si el rol también tiene el permiso de esa sección.

    Configura cada campo del formulario de ayuda para este rol. Un campo oculto no se puede editar, y uno que no se puede editar no puede ser obligatorio. Unidad de medida y cantidad solo aparecen para desplazamiento forzado.
